Orçamento de hospedagem e domínio

Comparação inicial para documentar uma escolha de publicação com custo, limites e adequação ao projeto.

Serviço Hospedagem Domínio Observação
GitHub Pages Gratuita .github.io gratuito Boa para site estático
Netlify Plano gratuito Domínio próprio contratado à parte Deploy simples por Git
Railway Plano com uso variável Domínio próprio contratado à parte Mais adequada se houver servidor

Escolha preliminar

Para a primeira versão estática do IncluiMais, GitHub Pages ou Netlify atendem ao escopo com menor complexidade. Valores comerciais devem ser pesquisados novamente na data da entrega e registrados na documentação.
