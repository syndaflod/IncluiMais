## Justificativa

A equipe escolheu a Vercel porque a integração com o Make é fácil, o uso é gratuito e a URL é personalizável.

**Custo atual:** R$ 0,00, com https://projetoincluimais.vercel.app.

**Se o projeto crescer:** um domínio próprio custaria a partir de R$ 40,00 por ano. Uso comercial exigiria rever o plano Hobby, que é destinado a uso pessoal e não comercial.
